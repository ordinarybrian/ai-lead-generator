# Email Signature

**Do not include a manual signature block in drafted email bodies.** Brian's email
client has this signature set as a default and appends it automatically, so a signature
written into the draft text would be redundant:

```
Brian Clark
Inland Elite Hosting
(208) 304-9811
brian@inlandelite.com
https://inlandelite.com
```

Reference it here only if the contact info itself is needed for some other purpose (e.g.
confirming a phone number). Drafts should end at the last line of actual message content
-- no "Brian Clark" sign-off, no repeated contact info.

For channels that are NOT sent through the email client and so don't get this
auto-signature (a website contact form, a LinkedIn message) -- flag this to Brian when
drafting rather than silently adding or omitting a sign-off, since the reasoning behind
this rule (the email client handles it) doesn't apply there.
