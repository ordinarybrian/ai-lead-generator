# EMAIL_QA.md

# SeniorCenter.com Brokerage
## Email Pass / Fail Checklist

Every outbound email must pass every section below.

If any item fails, rewrite the email.

---

# Test 1 — Human Test

Read the email out loud.

Question:

Would I actually say this in conversation?

PASS

- Sounds like natural speech.
- Slightly imperfect rhythm.
- Doesn't sound rehearsed.

FAIL

- Sounds like a blog post.
- Sounds like ChatGPT.
- Sounds like LinkedIn.
- Sounds like marketing copy.

---

# Test 2 — AI Test

Look specifically for AI wording.

FAIL immediately if you find phrases like:

It got me thinking...

The thought that followed...

It occurred to me...

It struck me...

The reason I'm reaching out...

I'd love to...

I'd welcome the opportunity...

I'd appreciate the opportunity...

Thank you for your consideration...

Please don't hesitate...

Furthermore...

Additionally...

Moreover...

With that in mind...

Against this backdrop...

In today's landscape...

In conclusion...

PASS

None of these appear.

---

# Test 3 — Corporate Buzzword Test

Count buzzwords.

Examples:

strategic

leverage

unlock

optimize

maximize

robust

scalable

holistic

ecosystem

synergy

category-defining

transformative

premium asset

digital asset

value proposition

brand asset

future-proof

If more than ONE appears...

FAIL

---

# Test 4 — Sales Test

Question:

Does this sound like someone trying to sell something?

PASS

Feels like sharing an idea.

FAIL

Feels like a pitch.

---

# Test 5 — Executive Test

Imagine the recipient opens this between meetings.

Would they read to the end?

PASS

Likely yes.

FAIL

Too long.

Too polished.

Too much explanation.

---

# Test 6 — Curiosity Test

Question:

Does the email create curiosity?

PASS

The reader wants to know more.

FAIL

The email explains everything.

---

# Test 7 — Vision Test

Question:

Can the recipient imagine using SeniorCenter.com?

PASS

The email paints a picture.

FAIL

The email only talks about the domain.

---

# Test 8 — Personalization Test

Question:

Could I replace the company name with another company and send the same email?

If yes...

FAIL

The email must clearly be written for THIS organization.

---

# Test 9 — One Idea Test

Question:

What is the single point?

If you cannot answer in one sentence...

FAIL

---

# Test 10 — CTA Test

Question:

Is the ask small?

PASS

Reply.

Conversation.

Referral.

Thoughts.

FAIL

Meeting.

Sale.

Pricing.

Negotiation.

---

# Test 11 — Adjective Test

Highlight every adjective.

If there are more than about one adjective every two sentences...

FAIL

---

# Test 12 — "Could" Test

Count the word "could."

0–2

PASS

3+

Rewrite.

---

# Test 13 — Reading Level

The email should read around:

8th–10th grade.

If it sounds like Harvard Business Review...

FAIL

---

# Test 14 — Paragraph Test

Maximum paragraph length:

4 lines.

If larger...

FAIL

---

# Test 15 — Word Count

Ideal:

120–220 words

Maximum:

250

Over 250

FAIL

---

# Test 16 — Rewrite Test

Delete the first paragraph.

Is the email better?

If yes...

The first paragraph was unnecessary.

Rewrite.

---

# Test 17 — Remove One Sentence

Delete one random sentence.

Does the email still work?

If yes...

That sentence wasn't needed.

Rewrite.

---

# Test 18 — Forward Test

Question:

Would the recipient comfortably forward this internally?

PASS

FAIL

---

# Test 19 — Memory Test

After reading, close the email.

Can you summarize it in ONE sentence?

If not...

FAIL

---

# Test 20 — "Why Them?" Test

Finish this sentence:

"I emailed this company because..."

If you can't answer in one sentence...

FAIL

---

# Final Gate

Imagine the recipient is:

- Anna Banks, CMO of AARP
- Chris Milone, CMO of A Place for Mom
- David Cygan, CMO of Brookdale Senior Living

Would you confidently send this email exactly as written?

YES

PASS

Anything else

FAIL

Rewrite.

---

# Final Principle

The email should feel like one intelligent person sharing one interesting idea with another intelligent person.

Not marketing.

Not AI.

Not sales.

Just an idea worth considering.
